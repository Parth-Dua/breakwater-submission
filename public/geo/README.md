# Bundled coastline

Natural Earth 1:50m coastline, public domain. Coordinates rounded to five decimal places; NL/BR assets retain regional segments. World fallback covers other historical ports.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_coastline.geojson

These are map context only; port limits, berth boundaries and AIS come from the simulated company records.
